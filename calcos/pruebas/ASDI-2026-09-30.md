# Cierre de ASDI y borrado individual de instalaciones

Base: a2f3ca2b26bc61bb08081ec3b7c012029f5ab5db.

Al seleccionar ASDI desde G-4, el panel cambiaba la herramienta, pero el mapa no la recibía: faltaba Mi (panel G-4) en la condición herramientaOps. El mismo error afectaba las vistas 2D y 3D, que comparten el mapa lógico.

Cambios limitados:
- Conectar G-4 con la herramienta del mapa.
- CERRAR ÁREA, Enter, doble clic y clic en el primer vértice comparten el cierre del polígono. Se requieren tres vértices; el aviso conserva el dibujo si faltan puntos.
- Guardar los últimos puntos en una referencia para evitar perder el último clic al terminar rápidamente.
- CANCELAR TRAZADO descarta únicamente el trazado pendiente.
- Desactivar la herramienta al cerrar correctamente.
- Las fichas y los vértices de previsualización no interceptan el dibujo.
- Clic en una instalación abre su nombre y ELIMINAR INSTALACIÓN. El borrado requiere confirmar y utiliza el id existente. Las unidades convencionales conservan su acción de clic.

No se cambia el servidor, el formato de ejercicios ni los datos guardados. Las instalaciones existentes usan el mismo componente y reciben el menú al abrir el ejercicio.

Reproducción: desde raíz, python calcos/pruebas/construir-asdi.py. Cada sustitución exige un ancla única sobre index-ge-import-20260929.js. El script reproduce exactamente el nuevo compilado.

Validación: node --check; e2e/asdi.js con Chromium, datos ficticios y tiles locales; plan-fuegos-modelo.js (16 casos) aprobado. La prueba histórica reemplazos-compilado.js ya falla en 10 casos con el compilado base index-ge-import-20260929.js; compara hashes de una cadena anterior a la importación Google Earth. No se altera esa prueba en esta corrección.

Reversión: cambiar en calcos/index.html el script a ./assets/index-ge-import-20260929.js. Se conserva ese archivo anterior.
